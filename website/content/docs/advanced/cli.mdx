## Installation

The CLI (`trident`) is a separate project and must be installed independently as a .NET tool:

```bash
dotnet tool install --global TridentCore.Cli
```

## Global Options

| Option | Description |
|--------|-------------|
| `--json` | Output results as JSON |
| `--no-interactive` | Disable interactive prompts |
| `--verbose` / `--debug` | Increase output verbosity |

The CLI and desktop app can use the same instance home through `TRIDENT_HOME` or `~/.trident.home`, but CLI accounts, repositories, and settings are stored separately. See [Custom Data Directory](/docs/guides/custom-data-directory) for path selection.

## Instance Commands

### Create an Instance

```bash
trident instance create --name "My Modpack" --identity my-modpack --version 1.21.1 --loader net.fabricmc:0.16.10
```

Options:
- `--name`, `--version`, and an instance key (`--identity` or `--id`) are required by the current CLI validation.
- `--loader` takes a loader ID and version (LURL), such as `net.fabricmc:0.16.10`. Use `trident loader list` for supported IDs.

### List Instances

```bash
trident instance list
```

### Inspect an Instance

```bash
trident instance inspect --instance my-modpack
```

Shows the instance's profile and package information.

### Deploy (Build) an Instance

```bash
trident instance build --instance my-modpack
```

Runs the full deploy pipeline. Equivalent to clicking "Deploy" in the GUI.

### Launch an Instance

```bash
trident instance run --instance my-modpack --username Steve
```

Deploys, then launches Minecraft using a CLI account or the supplied offline username. CLI account storage is separate from the desktop app.

### Export a Modpack

```bash
trident instance export --instance my-modpack --format modrinth --author Steve --output ./my-modpack.mrpack
```

Supported formats: `trident`, `curseforge`, `modrinth`, `multimc`.

### Import a Modpack

```bash
trident instance import ./my-pack.mrpack
```

Auto-detects the format.

### Delete an Instance

```bash
trident instance delete --instance my-modpack
```

## Package Commands

### Search for Mods

```bash
trident package search --repository modrinth "sodium"
```

### Add a Mod

```bash
trident package add --instance my-modpack pref://modrinth/aC3cM3Vq
```

A Pref has the form `pref://repository/project-id` or `pref://repository/project-id@version-id`. Use the Pref returned by search rather than a display name.

### List Installed Mods

```bash
trident package list --instance my-modpack
```

### Enable / Disable a Mod

```bash
trident package enable --instance my-modpack pref://modrinth/aC3cM3Vq
trident package disable --instance my-modpack pref://modrinth/aC3cM3Vq
```

### View Available Versions

```bash
trident package version list pref://modrinth/aC3cM3Vq
```

### Pin a Specific Version

```bash
trident package version set --instance my-modpack pref://modrinth/aC3cM3Vq@9I21YYxf
```

## Loader Commands

### List Supported Loaders

```bash
trident loader list
```

### Change the Loader

```bash
trident loader set --instance my-modpack net.fabricmc:0.16.10
```

## Account Commands

### Add a Microsoft Account

```bash
trident account add --type microsoft
```

Launches the Device Code Flow in the terminal.

### Add an Offline Account

```bash
trident account add --type offline --username Steve
```

### List Accounts

```bash
trident account list
```

### Remove an Account

```bash
trident account remove --uuid 00000000-0000-0000-0000-000000000000
```

## Repository Commands

### List Configured Repositories

```bash
trident repository list
```

### Check Repository Status

```bash
trident repository status
```

### Add a Repository

```bash
trident repository add --label my-repo --driver modrinth --endpoint https://api.modrinth.com
```

## MCP Mode

Start an MCP server for AI agent integration:

```bash
trident --mcp
```
