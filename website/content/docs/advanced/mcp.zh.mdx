## 什么是 MCP？

模型上下文协议（Model Context Protocol，MCP）是 AI 智能体与外部工具交互的标准。Polymerium 的 CLI（`trident`）可以作为 MCP 服务器运行，暴露 30 多个工具供 AI 智能体直接调用。

智能体可以通过这些工具创建实例、查看和添加包、选择版本，以及导出整合包。部署、游戏启动和快照仍需在桌面应用中操作；部署和启动也可使用 CLI 命令。

## 启动 MCP 服务器

```bash
trident --mcp
```

这会通过 stdio 启动本地 MCP 服务器。先单独安装 `trident` CLI，再让 MCP 客户端连接它。

## AI 客户端配置

### Claude Desktop

添加到你的 `claude_desktop_config.json`：

```json
{
  "mcpServers": {
    "polymerium": {
      "command": "trident",
      "args": ["--mcp"]
    }
  }
}
```

### Cursor

在 Cursor 的设置中添加为 MCP 工具服务器，指向 `trident --mcp`。

### 其他客户端

任何支持通过 stdio 使用 MCP 的客户端都可以连接。服务器使用标准的 MCP 协议。

## 可用工具（30+）

### 实例工具

| 工具 | 说明 |
|------|-------------|
| `instance_list` | 列出所有实例 |
| `instance_inspect` | 查看实例详情 |
| `instance_create` | 创建新实例 |
| `instance_delete` | 删除实例 |
| `instance_unlock` | 解除导入实例的源绑定 |
| `instance_reset` | 清空运行目录（`build/`）；未放入本地保留（`persist/`）的数据会丢失 |
| `instance_export` | 将实例导出为整合包 |
| `instance_import` | 导入整合包文件 |
| `instance_install` | 从资源仓库安装整合包，创建新实例 |

### 包工具

| 工具 | 说明 |
|------|-------------|
| `package_list` | 列出已安装的包 |
| `package_search` | 在 CurseForge / Modrinth 搜索包 |
| `package_add` | 通过 Pref 添加包 |
| `package_inspect` | 查看包详情 |
| `package_enable` / `package_disable` | 切换包状态 |
| `package_dependency_list` | 列出包的依赖项 |
| `package_dependent_list` | 列出当前实例内依赖指定包的已安装包 |
| `package_version_list` | 列出可用版本 |
| `package_version_set` | 固定特定版本 |

### 加载器工具

| 工具 | 说明 |
|------|-------------|
| `loader_list` | 列出支持的模组加载器 |
| `loader_version_list` | 列出可用的加载器版本 |
| `loader_get` / `loader_set` | 获取或设置加载器 |

### 配置工具

| 工具 | 说明 |
|------|-------------|
| `config_get` / `config_set` | 读取/写入配置 |
| `config_list` / `config_unset` | 列出或移除配置键 |

### 账户工具

| 工具 | 说明 |
|------|-------------|
| `account_list` | 列出账户 |
| `account_add_offline` | 添加离线账户 |
| `account_remove` | 移除账户 |

### 仓库工具

| 工具 | 说明 |
|------|-------------|
| `repository_list` | 列出已配置的仓库 |
| `repository_status` | 检查仓库连接状态 |
| `repository_add` / `repository_remove` | 添加或移除仓库 |

### 原生 Patch 工具

| 工具 | 说明 |
|------|------|
| `patch_list` | 列出实例的导入层和用户层 Patch |
| `patch_set_enabled` | 启用或禁用 Patch |
| `patch_move` | 在所属层内调整 Patch 顺序 |

## 示例：建立包列表

以下调用使用当前服务器实际提供的工具名和必填参数：

```text
instance_create(name="Performance", version="1.21.1",
                loader="net.fabricmc:0.16.10", identity="perf-pack")
package_search(query="sodium", repository="modrinth")
package_add(pref="pref://modrinth/aC3cM3Vq", instance="perf-pack")
```

搜索结果会给出所选包的 Pref。加入包只会保存配置引用；使用桌面应用或 `trident instance build --instance perf-pack` 完成部署。更改版本前如需[快照](/docs/managing/snapshots)，请先在桌面应用中创建。

## 限制

- MCP 经本地 stdio 运行，不提供部署、游戏启动、创建快照或微软账号登录工具。
- 包工具修改的是实例配置；只有部署时才会准备游戏文件。
- CLI 账号设置与桌面应用的账号分开存储。两端可访问同一实例，不要同时修改同一实例。
