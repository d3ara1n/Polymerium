Polymerium is a cross-platform, open-source Minecraft launcher built around a declarative instance profile:

**Your instance is defined by a profile, not by a pile of file copies.**

Polymerium stores downloaded package files in a shared cache and deploys each instance from its profile, Pack Source, and Local Data. This keeps managed files reusable while leaving you in control of data created by the game.

## Where to Start

- **New to Polymerium?** Follow the [Getting Started](/docs/getting-started/installation) guide — you'll be playing in minutes.
- **Coming from another launcher?** Check the [Migration Guide](/docs/guides/migrate-from-other-launchers) for a quick transition.
