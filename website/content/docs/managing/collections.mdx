---
title: Collections
description: Organize an instance's packages into named groups and convert them to or from recipes.
---

A collection is a named [package group](/docs/managing/package-groups) stored in the instance profile. Use it to organize packages within one instance. For a separately maintained list you can apply to other instances or share, use a [recipe](/docs/managing/recipes).

The collection name is its identity: packages assigned to the same name form one group. There is no separate definition, Minecraft version, or mod loader. Group priority, duplicate packages, and the loose group follow the shared rules in [Package Groups & Override Order](/docs/managing/package-groups).

## Move Packages into a Collection

1. Open an instance's **Setup** page.
2. Open a loose package's menu and choose **Move into Collection**. Select an existing collection or enter a new name.
3. To move several packages, open the menu under **Get More** and choose **Batch Move to Collection**. Review the selection before assigning a destination.

You can move packages between collections. You can also drag an eligible package onto an existing collection using the drag panel. Tags stay on each entry when it moves.

Packages belonging to a modpack or recipe group retain their source association and cannot be assigned directly to a collection. To reorganize a recipe group locally, convert it to a collection first.

## Rename or Leave a Collection

Use the collection header menu to **Rename Collection**. Renaming it to an existing collection's name merges the groups.

On a member's menu, **Remove from Collection** keeps the package entry and makes it loose. On the group header, **Disband Group** does this for every member, while **Remove Group** deletes the group's entries from the instance profile. Moving entries to the loose group gives them the highest package priority, so check for duplicate projects before deploying again.

## Convert to or from a Recipe

The collection header menu can **Promote to Recipe**. Polymerium creates a recipe from the collection's package references and tags, then associates the group with that recipe. Notes are not generated.

The recipe header can **Demote to Collection** to keep the packages grouped locally under the recipe's name without referencing the recipe. It does not delete the recipe from the Recipes library. If a collection with that name already exists, the packages join it.

These conversions change group membership. Review the [group order](/docs/managing/package-groups) afterward if you rely on overrides between groups.

## Collections in Modpacks

Locally imported modpacks use modpack groups, which do not support collection operations such as renaming or moving individual members. Online Trident export can carry existing collection grouping and order, and converts local recipe groups into collections. Excluding source information also converts modpack groups into collections. Other formats do not preserve this grouping metadata. See [Import & Export](/docs/managing/import-export) for the archive contents and source association options.
