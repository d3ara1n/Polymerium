# Polymerium 发布片视觉规范

## 品牌与界面

品牌标识原样使用 `assets/logo.svg`，不修改金色、不重新绘制。深色背景使用官方深色版。

UI 用 HTML/CSS 实现，信息层次以当前桌面应用为依据；视频字号、轮廓、间距允许整体放大。品牌金用于焦点、选中态和主要按钮。保留实际产品的克制边框、小圆角、侧栏和密集列表风格，不改成通用圆角大胶囊网站。

来源：

- `../assets/brand/README.md`：金色 `#EEA93B`、米白 `#E9E4D8`、交织 Logo。
- `../src/Polymerium.Avalonia/Controls/InstanceCard.axaml`：来源、图标、名称、加载器与版本、标签的信息顺序。
- `../src/Polymerium.Avalonia/Pages/InstancePage.axaml`：独立底板侧栏、图标导航、选中行的金色指示。
- `../src/Polymerium.Avalonia/Pages/InstanceSetupPage.axaml`：包分组与列表、筛选及工具栏。

暖黑背景和舞台上的立体排列是视频呈现，不作为软件界面的精确色值声明。具体 UI 文案与结构需要贴近产品，示例实例与包名称明确只是演示数据。

## 三种画面材料

1. 模拟 UI：按钮、行、图标、选择状态都独立成 DOM 元素，承担操作与状态变化。
2. 概念场景：卡片从散列到归入实例，表达组织关系；抽象移动不等同于软件支持拖放操作。
3. 真实截图：只在独立展示镜头作为整体平面展开。未提供时显示明确的截图插槽，禁止用仿制 UI 冒充实拍。

## 构图

1080p 主标题 78–112px，副标题 28–38px，模拟 UI 主要文字 26–34px。每幕有清晰主角。关键字、UI 主体和结尾网址保持可读；展示镜头中的截图只负责整体产品印象，不需要逐字阅读。

字体使用固定版本 `@fontsource-variable/noto-sans-sc` 的本地 WOFF2 和字重，遵循该依赖附带的 OFL 许可；不依赖在线字体或系统字体回退。应用内实际字体可能受用户设置影响，这里是视频用字。

## 动效

一条持续向左的运动主线连接各幕；操作镜头内部用卡片/选中项带领视线。入场、重排、选择、结果揭示都承担信息推进。先动作，停顿约 0.4 秒，再揭示结果。禁用循环漂浮、呼吸光晕和无依据的数字滚动。

截图扇形展开采用三张独立平面的旋转与位移，保持共同中心；先展开，再通过镜头收回进入启动场景。截图占位标记仅属于当前预览，正式成片前必须消除。

## 声音

最终采用无歌词、清晰节拍的电子配乐；动作点用少量轻触、移动、落定音效。初稿静音以便先判断结构与画面。无需旁白和语音字幕。
