# Native Patch 编辑器

## 背景

Trident 的 Native Patch 能力刚完成，已经可以表达影响部署和启动的外部声明，但 Polymerium 目前还没有对应的用户界面。整合包开发者只能通过文件管理或其他工具处理这部分内容，导致关键的发布和启动行为不在应用的开发工作流中。

## 做什么

为 Native Patch 提供面向开发者的管理和编辑入口，使用户能够查看、理解和调整 Patch，并知道它对实例部署、启动和导出的影响。

## 期望效果

Patch 成为整合包开发工作流中的可见组成部分。开发者可以在不离开 Polymerium 的情况下管理 Patch，审阅其变更和应用结果，并减少因直接编辑底层文件造成的格式错误或发布遗漏。

## 注意事项

需要区分整合包携带的 import 层 Patch 与本机用户层 Patch，并保持 Trident 对 Patch 顺序、启用状态、作用范围和导出边界的语义。具体编辑形式和支持的 Patch 项目不在本构想中预先限定。
