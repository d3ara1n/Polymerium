# Recipe UX QOL

实例包列表分组 UI（InstanceSetupPage）的体验打磨项。目标：组头与导引线的操作感、状态记忆与顺序控制。

## 1. 导引线交互

- **做什么**：Entry 左侧导引线（`RequireGuideLine`）支持 hover 高亮与点击定位。
- **期望效果**：鼠标划过导引线时高亮，点击导引线展开并定位到对应组，类似 IDE 代码缩进线的交互。
- **注意事项**：当前导引线纯视觉（单色 2px 竖线），无任何交互；散装组不画导引线（`LooseGroupModel.RequireGuideLine = false`），交互只覆盖有组头的组。

## 2. 组展开态持久化

- **做什么**：组的折叠/展开状态跨页面会话保留。
- **期望效果**：用户折叠的组，下次进入该实例的 Setup 页仍是折叠的。
- **注意事项**：`GroupModelBase.IsExpanded` 当前默认 true、每次打开页面重置；页面模型生命周期短（导航离开即销毁），状态必须落在页面模型之外（实例级持久层），且要处理组消失后的过期状态。

## 3. 组拖拽排序

- **做什么**：组头支持拖拽改组间顺序。
- **期望效果**：拖拽组头调整组顺序，顺序写入 `SourceOrders`（组间排序的既有数据源）。
- **注意事项**：`SourceOrders` 排序机制已存在（`PackageListItemComparer` 消费），缺的只是拖拽 UI 与写入路径；包级顺序（`PersistentIndex`）与组间顺序互不影响；散装组恒沉底，不可参与拖拽。
