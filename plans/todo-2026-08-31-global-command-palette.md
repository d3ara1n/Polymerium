# 全局命令面板

## 背景

应用页面数量已不少（实例系列页、市场系列页、设置、维护等），页面间跳转依赖侧栏逐级点选，键盘用户没有快速通道。聚合搜索是桌面工具产品的成熟交互：一个搜索框聚合页面导航、实例与功能入口。经讨论确认要做；同期的拼音首字母搜索（见 `PINYIN-SEARCH.md`）是它的匹配能力基础之一。

## 做什么

一个应用内全局命令面板：任意页面按 Ctrl+K 唤起覆盖层，一个输入框搜所有——页面导航目标、实例，后续可扩设置项与市场入口。结果按来源分组，键盘上下选择、回车执行、Esc 关闭。

## 期望效果

- 键盘主导的快速导航：不碰鼠标两三步内到达任意页面或实例。
- 面板成为功能入口的统一收敛点，后续新入口（设置、市场、动作）只需注册即可被搜到。
- 搜索体验为中文用户优化（拼音首字母可命中）。

## 调研所得的注意事项

- **硬约束：不入侵系统。** 只用应用内按键（窗口获得焦点时生效），不注册系统级全局热键，不注册协议、不写注册表——卸载零残留是产品原则。
- 搜索源注册点集中在一处、经 DI 服务组合：不做特性扫描/反射发现，不引入静态单例，注册文件里一眼看到全部可搜内容。
- 面板按 overlay 体系走（Dialog/Modal 与 Model 命名配对，activator 激活），不另起导航机制。
- 搜索数据聚合不得阻塞 UI 线程；实例数据以 `ProfileManager`/`InstanceManager` 现有数据为准。
- 与 `PINYIN-SEARCH.md` 的关系：拼音匹配是通用检索能力，本面板是它的消费方之一；实例列表搜索同样是消费方，两者不互相依赖对方落地。
